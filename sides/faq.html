Frequently asked questions

Which mod loader does LAN Utility use?

LAN Utility uses NeoForge. The requested loader version is 26.3.0.97 for Minecraft 26.3.

Where can I get an older release?

All JAR files currently included with this website are listed on the download page.

How do I install a release?

Install the matching NeoForge version, then place the downloaded LAN Utility JAR in your Minecraft mods folder.

Does it work on large Servers?

Yes but you will need to follow all rules.
