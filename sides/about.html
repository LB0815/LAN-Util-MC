The project

About LAN Utility

LAN Utility is a Minecraft mod focused on making private multiplayer sessions easier to manage.

Built for playing together

The project provides a collection of utilities for private Multiplayer play. It uses NeoForge and is intended for players who want to troll their friend a little.

Current compatibility

The listed release target is Minecraft 26.3 with NeoForge 26.3.0.97. Check the download page for the available LAN Utility files.
